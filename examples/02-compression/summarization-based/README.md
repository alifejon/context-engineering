# Context Compression Example

압축 기법을 적용한 실전 예제입니다.

## 설치
```bash
pip install scikit-learn numpy tiktoken
```

## 사용법
```bash
python example.py
```

## 코드는 다음 압축 기법을 시연합니다:
1. 추출형 압축 (Extractive)
2. 의미적 중복 제거 (Semantic Deduplication)
3. 우선순위 기반 선택 (Priority-based Selection)

자세한 구현은 example.py를 참고하세요.
